## plateforme web sécurisant le cycle de livraison des projets d'une agence digitale : validation traçable, recette et paiement par étapes »


## Description :
Cette plateforme permet au client d'une agence digitale de suivre son projet, de valider les livrables de façon traçable et de tester le résultat avant de payer le solde, tandis que l'agence est protégée par un acompte.
À Vorona Agency, la proposition commerciale est envoyée au client par e-mail, mais le suivi, la validation et le paiement ne sont pas centralisés. L'objectif est de réaliser une plateforme web où le client suit l'avancement de son projet, valide les maquettes, teste le projet avant le solde, et où chaque décision laisse une trace datée.


## Fonctionnalités
- Suivi de l'avancement des projets (import Excel des tâches)
- Maquettes avec commentaires épinglés et validation horodatée
- Recette avant paiement du solde
- Paiement par étapes : acompte, puis solde
- Demandes de modification chiffrées
- Journal d'activité


## Technologies
- Backend : Node.js, TypeScript, TypeORM
- Base de données : PostgreSQL
- Frontend : React, TypeScript
